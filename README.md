# 🔊 Volume Control HandBall

A simple interactive volume control demo using HTML, CSS, and JavaScript. Click and hold the volume button, then release to launch a visual "volume ball" showing the power of your click.

## 📁 Files
- `index.html` – Main HTML structure
- `index.css` – Styling for the volume button and canvas
- `index.js` – Logic for mouse interaction, volume visualization, and animation

## 🚀 How to Run
1. Clone or download the repo.
2. Open `index.html` in your browser.

No dependencies or build tools required!

## ✨ Features
- Volume icon that responds to mouse clicks
- Animated ball representing "volume strength"
- Dynamic volume bar with percentage markers
